Interaction notes

This template opens on the model catalog, even when a model is already active.

  1. Other models is a destination. It replaces generic back language and stays available from every setup screen.
  2. Presets remain first-class. “My setups” lists reusable model-and-settings combinations and supports deleting or creating them.
  3. The current model is one click away. Its persistent teal navigation item shows both its name and active status.
  4. Color carries meaning. Teal is reserved for the applied model; indigo marks a candidate being configured.
  5. Selection stays explicit. Browsing or configuring never changes the active model until “Use” is pressed.
